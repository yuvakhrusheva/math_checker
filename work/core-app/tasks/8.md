# Task 8: Criteria Management UI screen

## Required Skills

Before executing this task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Build the Criteria Management Streamlit page for the math_checker app. This page allows operators to upload criteria JSON files, validates them on upload (schema + filename convention), displays a grid of currently loaded criteria combinations (grade × language × variant), and shows error messages for invalid uploads. Supports acceptance criteria CA-1, CA-2, CA-3. All interface text must be in English (CA-28).

## What to do

1. Create `pages/criteria_management.py` as a Streamlit page with:
   - A file uploader (`st.file_uploader`) accepting `.json` files
   - On upload: read file bytes and filename, call `criteria_loader.save_criteria_file(filename, content)`
   - On success: show `st.success("Loaded: <stem>")` (e.g. `"Loaded: grade3_ru_v1"`)
   - On validation error: show `st.error("Invalid criteria: [reason]")`, file not saved
   - A "Loaded Criteria" section (`st.subheader`) with a grid/table showing Grade 2 and Grade 3 (rows) × RU and AZ (columns); each cell lists variant availability (v1 ✓, v2 ✓, or — for missing)
   - Grid data sourced from `criteria_loader.list_available_combinations()`

2. Register the new page in `app.py` via `st.navigation` so it appears in the sidebar.

**Implementation hints:**
- Use `file.read()` to get bytes from the uploaded file object; pass `file.name` and the bytes to `criteria_loader.save_criteria_file`
- Wrap the call in a try/except to catch validation errors and display them via `st.error()`

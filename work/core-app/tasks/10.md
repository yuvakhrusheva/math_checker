# Task 10: Review Panel UI

## Required Skills

## Description

Build the Review Panel Streamlit page for operator review of low-confidence grading results. The page lists students requiring review grouped by cohort, shows full PDF page scans for each low-confidence task result, and allows operators to edit recognized answers with immediate score recalculation. Supports variant selection for students where the test variant could not be detected automatically. Covers CA-16 through CA-19.

## What to do

- Create `pages/review_panel.py` as a full Streamlit page
- Query DB for students with `status=requires_review`, group by cohort
- For each student, open an expander showing their low-confidence task results
- For students with `detected_variant=null`, show a variant selectbox (1 or 2); on change update DB and reload criteria
- For each task result with `confidence='low'`, render the full PDF page image (no bounding box) using `pdf_processor.pdf_to_images()`, show task number, recognized answer, and current score
- Allow operator to edit the answer via `st.text_input`; on change call `scorer.compute_score()` with the new answer and the student's criteria, save the result to DB with `manually_corrected=1`
- Provide a "Mark as Done" button per student that sets `review_status='done'` and `status='processed'`
- Validate PDF path is within `data/downloads/` before opening (path traversal guard)
- Show a warning and skip image if PDF file is not found on disk
- All UI text must be in English (CA-28)

**Read for reference:**
- `src/db.py`, `src/scorer.py`, `src/pdf_processor.py`

**UI layout:**
```
Page: Review Panel

[Students requiring review — grouped by cohort]
  For each cohort with requires_review students:
    st.subheader(f"{school} — {class_number}{class_letter}")

    For each student in cohort:
      st.expander(f"Student {student_id} — {recognized_name or 'Unknown'}")

      If detected_variant is None:
        st.selectbox("Select test variant", [1, 2])
        → on change: update db, reload criteria for this student

      For each task_result with confidence='low':
        st.write(f"Task {task_number} (Page {page_number})")
        → render page image: pdf_to_images(pdf_path)[page_number-1]
        → st.image(base64.b64decode(b64))

        st.text_input(f"Answer for Task {task_number}", value=recognized_answer)
        → on change: scorer.compute_score(new_answer, task_criteria) → update task_result in DB
        st.write(f"Score: {score} / {max_score}")

      st.button("Mark as Done") → db.update_student review_status='done', status='processed'
```

**PDF path:** `data/downloads/{cohort_id}/{filename}` — filename stored in students table

**Image rendering:** Call `pdf_processor.pdf_to_images(pdf_path)`, index by `page_number - 1`. Convert base64 to bytes with `base64.b64decode(b64_string)` before passing to `st.image`.

**Score recalculation:** Load criteria for the student's grade/language/variant, find the task entry, call `scorer.compute_score()`. No LLM re-call.

**Edge cases:**
- PDF not found in `data/downloads/` (deleted?) → show `st.warning`, skip image rendering
- `detected_variant=null` → block task display until variant is selected

**Security:** Resolve `pdf_path` and verify it is within `data/downloads/` using `os.path.realpath` before opening. Reject paths that escape the directory.

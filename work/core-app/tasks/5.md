# Task 5: PDF processor

## Description

Implement `src/pdf_processor.py` — a module that opens a PDF file using PyMuPDF (fitz), renders each page to JPEG at 150 DPI, and returns a list of `(page_number, base64_string)` tuples. The module must also define a typed `UnreadablePDFError` exception that is raised for corrupted or empty PDFs, so upstream callers can handle bad input gracefully without crashing the grading pipeline.

## What to do

1. Create `src/pdf_processor.py` with:
   - `class UnreadablePDFError(Exception)` — custom exception for unreadable PDFs
   - `pdf_to_images(pdf_path: str | Path) -> list[tuple[int, str]]` — opens PDF, renders each page at 150 DPI as JPEG, returns list of 1-based `(page_number, base64_jpeg_string)` tuples
2. Handle error cases: catch fitz.open failures, raise `UnreadablePDFError` for 0-page docs and render failures
3. Create `tests/fixtures/sample.pdf` — minimal valid PDF generated via fitz (1 page), committed to repo
4. Write unit tests in `tests/unit/test_pdf_processor.py` covering all TDD anchors below — write tests first, confirm they fail, then implement

## TDD Anchor

- `tests/unit/test_pdf_processor.py::test_pdf_to_images_valid` — valid sample.pdf → list of tuples, len >= 1, each tuple has (int, non-empty str)
- `tests/unit/test_pdf_processor.py::test_page_numbers_are_1based` — first page_number == 1
- `tests/unit/test_pdf_processor.py::test_base64_is_valid_jpeg` — decoded bytes start with JPEG magic bytes (FF D8 FF)
- `tests/unit/test_pdf_processor.py::test_corrupted_pdf_raises_unreadable` — corrupted bytes → UnreadablePDFError
- `tests/unit/test_pdf_processor.py::test_single_page_pdf` — single-page PDF → list of length 1
- `tests/unit/test_pdf_processor.py::test_multi_page_pdf` — multi-page PDF → correct count

## Details

**Files:**
- `src/pdf_processor.py` — implementation: `UnreadablePDFError`, `pdf_to_images`
- `tests/unit/test_pdf_processor.py` — unit tests (write first, TDD)
- `tests/fixtures/sample.pdf` — minimal valid 1-page PDF fixture; generate via fitz and commit to repo

**Dependencies:** PyMuPDF (`fitz` >= 1.24); tasks 2 and 3 must be complete before this task

**Edge cases:**
- PDF with 0 pages → raise UnreadablePDFError
- Corrupted PDF header → fitz.open raises → catch and re-raise as UnreadablePDFError
- PDF with a single page → list of length 1

**Implementation hints:**
- DPI matrix: `fitz.Matrix(150/72, 150/72)`
- Render to JPEG bytes: `pix.tobytes("jpeg")`
- page_number is 1-based: `page_num + 1` where `page_num` is the 0-based loop index
- Generate sample.pdf fixture with fitz: `doc = fitz.open(); doc.new_page(); doc.save("tests/fixtures/sample.pdf")`
- Do not put fixture generation in production code — use a script or conftest.py

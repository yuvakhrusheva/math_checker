```

```

### User

Manual walkthrough of all 6 verification steps:

1. Upload a valid criteria JSON → appears in grid
2. Try adding cohort without criteria → error shown
3. Run full pipeline on 5-PDF test folder → all statuses correct in DB
4. Open Review Panel → edit an answer → score recalculates
5. Export Excel → open file, verify 2 sheets, correct headers, student_id present
6. Close browser, reopen → all cohorts and results still visible

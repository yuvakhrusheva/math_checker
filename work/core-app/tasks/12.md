# Task 12: Code Audit

## Required Skills

Перед выполнением задачи загрузи:

## Description

Full-feature code quality audit of the core-app. Read all source files in `src/`, `pages/`, `app.py`, `tests/`. Review holistically: cross-module consistency, error handling completeness, thread safety in queue_processor, shared resource usage. Write audit report to `work/core-app/logs/code-audit.md`.

## What to do

- Read all source files: `src/`, `pages/`, `app.py`, `tests/`
- Audit cross-module consistency: naming conventions, error types, data formats
- Audit error handling completeness: all edge cases covered (UnreadablePDFError, JSONDecodeError, Drive failures)
- Audit thread safety: `queue_processor.py` — does it safely share state with Streamlit UI?
- Audit SQLite access patterns: WAL mode enabled, no pooling issues, parameterized queries everywhere
- Identify dead code or unused imports
- Evaluate function/class design: single responsibility, appropriate abstraction levels
- Check criteria JSON loading: is it loaded fresh each time or cached? (should be fresh to pick up new uploads)
- Write audit report to `work/core-app/logs/code-audit.md`
- If critical issues found: spawn a fixer task with code-reviewer as reviewer

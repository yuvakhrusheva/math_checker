# Task 1: Project infrastructure

## Required Skills

Перед выполнением задачи загрузи:

## Description

Set up the full project skeleton for math_checker — a local Streamlit app for AI-powered grading of handwritten math tests. This task creates all folders, configuration files, dependency declarations, pre-commit hooks, and the minimal Streamlit entry point. Everything downstream (LLM grading, Google Sheets sync, PDF processing) depends on this foundation being correct and reproducible.

The most critical requirement is secure handling of the Google service account key: the env var `GOOGLE_SERVICE_ACCOUNT_JSON` must point to an absolute path of a JSON file that lives **outside the repo root**, and `app.py` must validate this at startup — failing fast with a clear error if the var is missing, the path is relative, or the file does not exist.

## What to do

1. Create folder structure: `src/`, `criteria/`, `data/`, `tests/unit/`, `tests/integration/`, `tests/fixtures/llm_responses/`, `pages/` — add `.gitkeep` files where needed so git tracks empty dirs.
2. Write `requirements.txt` with all project dependencies pinned to minimum versions (see Details).
3. Write `config/settings.json` with LLM model name and generation settings.
4. Write `.env.example` documenting all required env vars with clear instructions — especially that `GOOGLE_SERVICE_ACCOUNT_JSON` must be an absolute path to a key file stored **outside the repo root**.
5. Update `.gitignore` to exclude `data/`, `.env`, `__pycache__`, `*.pyc`, `criteria/`.
6. Write `pytest.ini` configuring `testpaths = tests/unit tests/integration` and any needed markers.
7. Write `.pre-commit-config.yaml` with a gitleaks hook for secret scanning; run `pre-commit install`.
8. Write minimal `app.py`: call `init_db()` on startup, validate `GOOGLE_SERVICE_ACCOUNT_JSON` (must be set, must be absolute path, file must exist — raise clear error if not), then route to pages using `st.navigation`.

## TDD Anchor

Write these tests **before** implementing the startup validation in `app.py`. Run them, confirm they fail, then implement, then confirm they pass.

- `tests/unit/test_app_startup.py::test_invalid_path_raises_error` — when the env var is set to a relative path or a path that does not exist, startup validation raises a clear error

## Details

**Files:**
- `requirements.txt` — include: `streamlit>=1.36`, `litellm>=1.40`, `PyMuPDF>=1.24`, `google-api-python-client>=2.130`, `google-auth>=2.29`, `google-auth-httplib2>=0.2`, `pandas>=2.2`, `openpyxl>=3.1`, `python-dotenv>=1.0`, `pytest>=8.0`, `pytest-mock>=3.12`
- `config/settings.json` — `{"model": "claude-3-5-sonnet-20241022", "max_tokens": 2048, "temperature": 0}`
- `.env.example` — document `GOOGLE_SERVICE_ACCOUNT_JSON` (absolute path to service account JSON file, must be outside repo root) and `ANTHROPIC_API_KEY`
- `.gitignore` — add entries for `data/`, `.env`, `__pycache__/`, `*.pyc`, `criteria/`
- `pytest.ini` — `testpaths = tests/unit tests/integration`; add any markers used in tests
- `.pre-commit-config.yaml` — gitleaks hook for secret scanning
- `app.py` — minimal Streamlit entry point: load `.env`, call `init_db()`, validate env var, use `st.navigation` to route to pages in `pages/`

**Dependencies:** None — this is the first task.

**Edge cases:**
- `GOOGLE_SERVICE_ACCOUNT_JSON` is set but points to a file that does not exist → clear error
- `GOOGLE_SERVICE_ACCOUNT_JSON` is set to a relative path (e.g. `keys/service.json`) → clear error (must be absolute)
- `GOOGLE_SERVICE_ACCOUNT_JSON` is empty string → treat as not set

**Implementation hints:**
- Use `os.path.isabs()` to check if the path is absolute
- Use `os.path.isfile()` to check if the file exists
- Validate in a dedicated `validate_config()` function called at the top of `app.py` (before any Streamlit UI) so errors surface immediately
- `st.navigation` requires Streamlit >=1.36 — confirm version pin in requirements.txt matches

# Task 11: Excel exporter and Export UI

## Required Skills

Before executing this task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Implement Excel export functionality for the math checker app. `src/exporter.py` queries SQLite for all students across all cohorts and writes a timestamped `.xlsx` file with two sheets: "Answers" (raw task answers) and "Scores" (computed scores + performance levels). Students with `status=unreadable` are excluded; those with `status=error` get an ERROR marker in all task columns; those with `review_status=pending` get a PENDING marker. Grade 3 students get a computed performance level; grade 2 gets a blank. Rows are sorted school → class → student_id. `pages/export.py` provides a dedicated Export screen with an Export button, file download link, and an error list showing unreadable students with their error messages. Interface text in English. Supports CA-20 through CA-25.

## What to do

1. Implement `src/exporter.py`:
   - Query SQLite for all students across all cohorts (join with cohort data for school, class, teacher, test_date, grade)
   - Exclude students with `status=unreadable`
   - Build "Answers" DataFrame with columns: school, class, teacher, test_date, student_id, recognized_name, task_1_answer … task_16_answer
   - Build "Scores" DataFrame with columns: school, class, teacher, test_date, student_id, task_1_score … task_16_score, total_score, performance_level
   - For students with `review_status=pending`: fill all task columns with "PENDING"
   - For students with `status=error`: fill all task columns with "ERROR"
   - For valid grade 3 students: compute performance_level (81–100 → Advanced, 61–80 → Basic, 31–60 → Minimal, 0–30 → Insufficient)
   - For grade 2 students: leave performance_level blank
   - total_score: sum of all task scores (only for non-ERROR, non-PENDING rows)
   - Sort all rows: school → class (f"{class_number}{class_letter}") → student_id
   - Write to `pd.ExcelWriter(filename, engine='openpyxl')` with both sheets
   - Filename format: `results_YYYY-MM-DD_HH-MM.xlsx`

2. Implement `pages/export.py` (Streamlit Export page):
   - Display Export button: `st.button("Export to Excel")`
   - On click: call `exporter.export()`, show `st.download_button` with file bytes
   - Display error list: show students with `status=unreadable` along with their `error_message`
   - All interface text in English

3. Register the Export page in `app.py` via `st.navigation`

4. Write unit tests in `tests/unit/test_exporter.py` (TDD — write tests first, confirm they fail, then implement)

## Details

**Files:**
- `src/exporter.py` — Excel generation logic (create/implement)
- `pages/export.py` — Streamlit Export page (create/implement)
- `app.py` — register Export page in `st.navigation`
- `tests/unit/test_exporter.py` — unit tests (create/implement)

**Dependencies:** pandas, openpyxl (for Excel writing); tasks 7 (DB schema) and 8 (student data)

**Edge cases:**
- Student with `status=error` AND `review_status=pending` — ERROR takes precedence
- Grade 2 student with all tasks scored — performance_level must be blank string, not None/NaN
- Class sorting must sort by combined string f"{class_number}{class_letter}" (e.g. "3A"), not numerically
- total_score must be omitted (blank/NaN) for ERROR and PENDING rows, not 0
- Filename timestamp uses local time at export moment

**Implementation hints:**
- Use `pd.ExcelWriter(filename, engine='openpyxl')` with `with` block and `writer.sheets` to write both DataFrames
- Performance level logic: apply only where grade==3 and row is not ERROR/PENDING; use `pd.cut` or explicit conditions
- For `st.download_button`, read the generated file bytes with `open(filename, 'rb').read()`
- Class display: `f"{class_number}{class_letter}"` (e.g. "3A")
